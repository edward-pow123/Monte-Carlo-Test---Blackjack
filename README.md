# Monte-Carlo-Test---Blackjack
-Randomized Blackjack results to analyse how different moves by the player effect the result.
-This uses the xlsx writer library in python to write the results for analysis 
-It chooses a player randomly to become a dealer this means they have to deal if they're total is under 16 and cannot deal if their total is over 17
-It gives every player 2 random cards 
-It randomizes if they deal again provided they are not busted if they're not the dealer, they can deal infinate times until they are bust
-If they are the dealer they deal based on the rules for the dealer 
-Once every player has dealt it works out who won and writes this to a file and an .xlsx file
-This can be done as many times as you want to analyse the results more accurately
